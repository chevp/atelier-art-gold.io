
# Atelier Art Gold

Welcome to **atelier-art-gold.io** — the official homepage for Atelier Art Gold, a creative studio dedicated to providing exquisite, handcrafted artwork and designs. Atelier Art Gold offers a unique blend of tradition and innovation, capturing the essence of fine craftsmanship in every piece.

---

## Project Overview

This project hosts the official homepage of Atelier Art Gold, showcasing the studio’s portfolio, story, and services. Visitors can explore collections, learn about the artisans behind each work, and reach out for commissions or inquiries.

### Features

- **Portfolio Display**: Browse a curated selection of art and design work, with high-quality images and descriptions.
- **About Us Section**: Discover the philosophy and story of Atelier Art Gold, including the values and inspirations that drive the studio.
- **Services**: Learn about the range of offerings, from commissioned works to personalized design services.
- **Contact**: Get in touch directly through an integrated contact form.

---

## Technologies Used

This project is built with modern web development technologies to ensure a smooth and responsive experience:

- **Angular**: Front-end framework for a dynamic and engaging user interface.
- **SCSS**: For flexible and customizable styling.
- **HTML5 & CSS3**: Base markup and styling.
- **GitHub Pages**: Hosting platform for static content.

## Getting Started

To set up this project locally, follow these steps:

1. **Clone the repository**:
    ```bash
    git clone https://github.com/chevp/atelier-art-gold.io.git
    ```

2. **Navigate to the project directory**:
    ```bash
    cd atelier-art-gold.io
    ```

3. **Install dependencies**:
    ```bash
    npm install
    ```

4. **Run the project locally**:
    ```bash
    ng serve
    ```
    - Open your browser and navigate to `http://localhost:4200` to view the homepage.

## Deployment
